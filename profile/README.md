# Bambie Digital Works

Bambie Digital Works creates practical software, useful automation scripts, and
original games.

## What we do

- **Software** — practical applications and digital tools with clear,
  dependable user experiences.
- **Scripts and automation** — focused solutions that simplify repeatable
  workflows and reduce manual work.
- **Games** — original interactive experiences built around thoughtful systems,
  meaningful choices, and persistent consequences.

## Current project

Our current project is an original, UI-first Windows command-centre simulation.
Players run an underground facility built around an experimental interstellar
transit portal, interpreting telemetry, coordinating personnel, following
procedures, and responding to technical, medical, and security incidents under
pressure.

The project is in **early implementation**, with a focused playable vertical
slice as its first major target. A minimal operator shell is in place, built
with Godot 4 and C#/.NET, but no playable build has been published yet.

[Explore the project repository](https://github.com/Bambie-Digital-Works/Stargate-Command-Simulator)

## How we work

- **Usability with purpose** — interfaces should be clear, focused, and
  satisfying to use.
- **Meaningful systems** — software and games should respond predictably while
  giving each decision visible consequences.
- **Accessibility from the outset** — scalable UI, captions, remappable input,
  colour-safe alerts, pause, and adjustable time pressure are baseline goals.
- **Dependable engineering** — deterministic behaviour, reproducible testing,
  and resilient data support reliable releases.
- **Original creative identity** — production terminology, lore, characters,
  interfaces, artwork, and audio are developed as original material.
- **Responsible asset provenance** — creative assets must be original,
  commissioned with clear rights, or used under a verified compatible licence.
