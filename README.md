# Bambie Digital Works GitHub profile

This is the official GitHub organization-profile and shared community-health
repository for **Bambie Digital Works**, a digital studio creating practical
software, useful automation scripts, and original games.

The public organization profile is maintained in
[`profile/README.md`](profile/README.md) and is displayed on the
[Bambie Digital Works organization page](https://github.com/Bambie-Digital-Works).

## Branding

Canonical logo and icon assets live in [`brand/`](brand/) (navy + cyan
isometric 3D lockup and stack mark). See [`brand/README.md`](brand/README.md)
for website, app, and GitHub usage.

| Use | File |
|-----|------|
| Org / profile avatar | [`brand/github/avatar.png`](brand/github/avatar.png) |
| Repo social preview | [`brand/github/social-preview.png`](brand/github/social-preview.png) |
| README banner | [`brand/github/readme-banner.png`](brand/github/readme-banner.png) |

Org avatar and repository social preview images must be uploaded in GitHub
Settings — git cannot set those automatically.
